# Data-Cleaning-Visualization-Project

## 📌 About the Project

Data Cleaning and Visualization project using **Python, Pandas, NumPy, and Matplotlib**. The project focuses on preparing raw data by handling missing values, duplicates, and inconsistencies, followed by visualization to identify useful patterns and insights.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## 🔄 Project Workflow

1. Load the dataset
2. Explore the data
3. Handle missing values
4. Remove duplicate records
5. Identify and handle data inconsistencies
6. Perform data cleaning
7. Create visualizations
8. Analyze and interpret the results

## 🎯 Key Learning Outcomes

* Data cleaning and preprocessing
* Handling missing and duplicate data
* Data visualization
* Exploratory analysis
* Using Python libraries for data analysis
